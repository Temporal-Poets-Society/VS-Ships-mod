# Withdrawn rowing boat

The author withdrew the experimental rowing boat from the current release on 31 October 2026.
Ships dev.25 omits its recipe from runtime assets and hides every item variant from creative inventory and the handbook.
The entity, item and rendering assets remain registered to preserve boats already in test saves.
`rowboat-recipe.json` is an archival reference, not a packaged recipe. The asset generator no longer emits it.
